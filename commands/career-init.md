---
description: Set up your Career Memory store and profile
argument-hint: "[optional path]"
---

Use the `career-memory` skill.

Set up the Career Memory store. If the user passed a path in `$ARGUMENTS`, use
it as the store location (and tell them to export `CAREER_MEMORY_HOME` to that
path so it is found next time); otherwise use the default resolution order.

Run `init`, show them the resulting layout, and then help fill in `profile.md`:
role, focus, current goals. Ask for those in one short exchange, not a
questionnaire. If they would rather skip it, that is fine — say the profile can
be filled later and that capture works without it.
