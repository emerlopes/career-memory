---
description: Check what your career memory is missing and what is due
argument-hint: "[optional: github]"
---

Use the `career-memory` skill, following `references/proactive.md`.

Run `checkup` (add `--github` if the user asked for it, or if $ARGUMENTS
mentions GitHub) and tell the user where their career memory stands: how long
since the last capture, which weeks or months have entries but no summary,
candidates still waiting, and how many entries cannot be verified.

Lead with the one thing worth acting on, not the full report, and offer to do
it — write the summary, promote the candidates, or ask the impact questions.
Then let it go: this is a service, not a reminder loop.

Everything here is about the record, never about the work. "No evidence
attached" means a future reader has nothing to check — not that the work was
small.
